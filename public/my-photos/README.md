# अपनी फोटो कैसे लगाएँ

इस folder में चार JPG photos इन्हीं exact names से upload करें:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

## GitHub में upload करने का तरीका

1. ऊपर **Add file** दबाएँ।
2. **Upload files** चुनें।
3. अपनी चार photos चुनें और उनके नाम ऊपर दिए गए exact names रखें।
4. नीचे **Commit directly to the main branch** चुनें।
5. **Commit changes** दबाएँ।
6. Vercel deployment के लिए 1–2 मिनट रुकें, फिर website refresh करें।

ध्यान दें: Files असली JPG format में होनी चाहिए। केवल file का extension बदलना image conversion नहीं है।
